# Course Contents

Every lesson in the course, in order. A new lesson shows up here when it's ready to pull.

To read a lesson in VS Code, open it and press **Ctrl + Shift + V**. In the preview, click a link below to go straight to that lesson.

## Unit 0: Groundwork

Get set up, find your way around the command line and Git, and write your first programs. The unit ends with a project: a quiz program you write yourself.

| Lesson | What you'll do |
| --- | --- |
| [0.1: Your GitHub Account and Practice Repo](unit-0/0.1-github-account.md) | Make a GitHub account, turn on two-factor authentication, and create this repo |
| [0.2: Installing Your Tools](unit-0/0.2-install-tools.md) | Install VS Code, Git, Node.js, pnpm and Python, and tell Git who you are |
| [0.3: Your First Commit and Push](unit-0/0.3-first-commit.md) | Clone this repo, start your journal, and make your first commit and push |
| [0.4: Getting Around the Command Line](unit-0/0.4-command-line.md) | Make, copy, move and delete files from the terminal, and start your `work` folder |
| [0.5: Writing Clear Commit Messages](unit-0/0.5-commit-messages.md) | Read your history with `git log`, and write messages that say exactly what changed |
| [0.6: Your First Python Program](unit-0/0.6-first-python-program.md) | Write and run Python, read its errors, and build a program that turns a mark into a percentage |
| [0.7: Making Decisions with `if`](unit-0/0.7-decisions.md) | Choose what your program does with `if`, `elif` and `else`, and make `score.py` give a WASSCE grade |
