# Lesson 0.2: Installing Your Tools

**Unit 0: Groundwork** · About 1–2 hours

## Why this comes next

Developers write code on their own computers, then send it to GitHub. To do that, your laptop needs a few tools:

| Tool | What it does |
| --- | --- |
| **VS Code** | The editor where you'll write code. It also has a built-in terminal. |
| **Git** | Keeps track of every change you make, and sends your work to GitHub |
| **Node.js** | Runs JavaScript on your laptop. Many web tools need it. |
| **pnpm** | Downloads code packages that other people wrote. It keeps one copy of each, which saves data. |
| **Python** | A programming language you'll use later in the course |
| **GitHub CLI** | Optional: a backup way to sign in to GitHub |

You'll download all of them today, in one session. After that, most of your work happens offline.

## Objectives

By the end of this lesson, you can:

- Open a Git Bash terminal inside VS Code.
- Get a version number from Git, Node.js, pnpm, Python and the GitHub CLI, using one command each.
- Show the name and email Git puts on your work, with `git config --global --list`.

## What you need

- Your laptop, plugged in
- A good internet connection. The downloads add up to a few hundred megabytes.
- About an hour, with time to spare

## Step 1: Open a terminal

A **terminal** is a window where you type commands instead of clicking. It looks plain, but developers use it all day. You'll get used to it.

1. Right-click the **Start** button (the Windows logo).
2. Click **Terminal**. On some laptops it's called **Windows PowerShell**. Either one works.

A window opens with a blinking cursor. That's where you type.

## Step 2: Install the tools with winget

`winget` comes with Windows. It installs programs for you, so you don't have to find each website.

Type each command below, then press **Enter**. Wait for it to finish before typing the next one.

```
winget install --id Microsoft.VisualStudioCode -e
```

```
winget install --id Git.Git -e
```

```
winget install --id OpenJS.NodeJS.LTS -e
```

```
winget install --id pnpm.pnpm -e
```

```
winget install --id GitHub.cli -e
```

What to expect:

- The first time, winget may ask you to accept its terms. Type `Y` and press **Enter**.
- Windows may ask, "Do you want to allow this app to make changes?" Click **Yes**.
- A command is done when you see **Successfully installed** and the blinking cursor comes back.

If a command shows an error, take a screenshot and send it to me. Then carry on with the next one.

## Step 3: Install Python

Install Python from its website instead, because there's a setting you need to choose.

1. Go to [python.org/downloads/windows](https://www.python.org/downloads/windows/).
2. Under the newest **Python 3** release, download the **Windows installer (64-bit)**.
3. Open the file you downloaded.
4. **On the first screen, tick "Add python.exe to PATH".** This step is important. Without it, typing `python` in the terminal won't work.
5. Click **Install Now**, and click **Yes** if Windows asks.

## Step 4: Make Git Bash your terminal in VS Code

Git came with its own terminal, called **Git Bash**. Most guides and tutorials use Git Bash commands, so you'll use it too.

1. **Close the terminal window** from Step 1. New programs only work in a terminal opened after they were installed.
2. Open **VS Code** from the Start menu.
3. Press **Ctrl + Shift + P**. A search box opens at the top. This is the **Command Palette**.
4. Type `Terminal: Select Default Profile` and press **Enter**.
5. Choose **Git Bash**.
6. Open the terminal inside VS Code: click **Terminal** in the top menu, then **New Terminal**. (The shortcut is **Ctrl + `` ` ``**. The `` ` `` key is usually under **Esc**.)

The terminal opens at the bottom of VS Code. From now on, this is where you'll type commands.

## Step 5: Check that everything works

In the VS Code terminal, type each command and press **Enter**. Each one should print a version number.

```
git --version
node --version
pnpm --version
python --version
gh --version
```

The numbers don't need to match anyone else's. If a command says **command not found**, or opens the Microsoft Store, write down which one and tell me.

## Step 6: Tell Git who you are

Git puts your name and email on every change you save. Set them once:

```
git config --global user.name "Your Name"
```

Use your real name, inside the quotes.

For the email, use the one you signed up to GitHub with. That's how GitHub knows the changes are yours.

```
git config --global user.email "you@example.com"
```

Check both settings:

```
git config --global --list
```

You should see your `user.name` and `user.email`.
