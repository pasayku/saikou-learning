
```

```

`print` shows something on the screen. What goes inside the brackets is what gets shown. The quote marks tell Python that `Hello, world!` is **text**, not an instruction. Text inside quotes is called a **string**.

## Step 4: Break it on purpose

Every programmer sees errors every day, so it's worth learning to read them now, while the program is two lines long.

Delete the closing `"` on the first line, so it reads:

```python
print("Hello, world!)
```

Save and run it again (press **↑** to bring back the command). Python stops and shows something like this:

```
  File "/c/Users/saku/projects/saikou-learning/work/unit-0/hello.py", line 1
    print("Hello, world!)
          ^
SyntaxError: unterminated string literal (detected at line 1)
```

Read an error from the **bottom** up:

- **The last line** gives the error's name, `SyntaxError`, and what went wrong. *Syntax* means the rules for how code is written. *Unterminated string literal* means a string that never ends: you opened a quote and didn't close it.
- **Above that**, Python shows which file, which line (`line 1`), and the code itself, with a `^` near the problem.

Put the `"` back, save and run it again to check it works.

> [!TIP]
> **When you're stuck on an error, send me the whole thing**, from the first line to the last. The last line alone often isn't enough.

## Step 5: Comments

A line starting with `#` is a **comment**. Python skips it. Comments are notes for people reading the code, including you, months from now.

Add a comment at the top of `hello.py`:

```python

print("I'm learning Python.")
```

Run it. The output is the same as before.

## Step 6: Variables

A **variable** is a name for a value, so you can use it again later. Add these lines to the bottom of `hello.py`:

```python
name = "Saikou"
country = "The Gambia"
print(name)
print(country)
```

`name = "Saikou"` means *store `"Saikou"` under the name `name`*. The `=` doesn't mean "equals" the way it does in maths. Read it as "store" or "becomes".

Notice that `print(name)` has no quotes. Without quotes, Python looks up the variable and prints its value, `Saikou`. With quotes, `print("name")` prints the word `name`.

**Naming variables.** Use small letters, and join words with an underscore: `first_name`, `exam_mark`. No spaces, for the same reason you didn't use spaces in folder names. Python programmers call this style *snake_case*. Put one space on each side of the `=`.

## Step 7: Put variables in a sentence

To mix text and variables, use an **f-string**: an `f` just before the opening quote, and each variable in curly brackets `{}`. Add this line:

```python
print(f"My name is {name}, and I live in {country}.")
```

Run it. The last line of the output should be:

```
My name is Saikou, and I live in The Gambia.
```

Now misspell a variable on purpose. Change `{country}` to `{contry}`, save and run it. The last line of the error says:

```
NameError: name 'contry' is not defined. Did you mean: 'country'?
```

Python doesn't know any variable called `contry`. It even guesses what you meant. Fix it and run again.

Write your own sentences, and have some fun with them. They don't have to be serious. Run it, and fix any errors the way you just learned.

## Step 8: Numbers

Numbers don't need quotes. Add these lines:

```python
mark = 42
total = 50
print(mark + total)
print(mark / total)
print(mark / total * 100)
```

Run it. At the bottom of the output, you'll see `92`, then `0.84`, then `84.0`.

| Sign | Means |
| --- | --- |
| `+` | Add |
| `-` | Subtract |
| `*` | Multiply |
| `/` | Divide |

Dividing always gives a number with a decimal point, even when it comes out whole. That's why you see `84.0`, not `84`.

## Step 9: Ask a question

So far, your program says the same thing every time. `input` lets it ask the person running it for something.

Make a new file:

```
cd work/unit-0
touch score.py
code score.py
```

Type this in:

```python
mark = input("Your mark: ")
total = input("Out of: ")
print(mark + total)
```

Save and run it:

```
python score.py
```

The terminal shows `Your mark:` and waits. Type `42` and press **Enter**. Then type `50` for `Out of:`, and press **Enter**.

You'll probably expect `92`. Python prints `4250`.

That's because **`input` always gives you a string**, even when you type a number. Adding two strings sticks them together: `"42"` + `"50"` is `"4250"`. Python doesn't know the text `42` is meant to be a number.

Now try dividing. Change the last line to:

```python
print(mark / total)
```

Run it again. This time the last line of the error says:

```
TypeError: unsupported operand type(s) for /: 'str' and 'str'
```

`str` is Python's short name for a string. Python can't divide one piece of text by another.

**The fix:** turn the answer into a number with `int`, short for *integer*, a whole number. Wrap it around `input`:

```python
mark = int(input("Your mark: "))
total = int(input("Out of: "))
print(mark / total)
```

Count the brackets: two to open, two to close. Run it, type `42` and `50`, and you get `0.84`.

## If something goes wrong

- **`python: can't open file ... No such file or directory`:** you're in a different folder from the file. Run `pwd` and `ls`. To run `score.py`, you need to be in `work/unit-0`.
- **The terminal shows `>>>`:** you typed `python` without a file name, so Python is waiting for you to type code. Type `exit()` and press **Enter** to get back.
- **You changed the code, but the output didn't change:** you didn't save. Look for a dot on the file's tab in VS Code. Press **Ctrl + S**, then run it again.
- **`ValueError: invalid literal for int() with base 10`:** you typed something that isn't a whole number, like `42.5` or `forty`. Run it again and type a whole number.
- **`SyntaxError: '(' was never closed`:** a bracket is missing. Count them: each `(` needs a `)`.
- **Some other error?** Read the last line and the line number, check that line, and send me the whole error if you're still stuck.
