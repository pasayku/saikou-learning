## Step 3: Your first loop

Make a new file:

```
cd work/unit-0
touch loops.py
code loops.py
```

Type this in:

```python
# Practice with while loops
count = 5
while count > 0:
    print(count)
    count = count - 1
print("Go!")
```

Run it:

```
python loops.py
```

You should see `5`, `4`, `3`, `2`, `1`, then `Go!`.

A `while` loop looks like an `if`: a condition, a `:`, and an indented block. The difference is what happens at the end of the block. An `if` runs its block once and moves on. A `while` goes back to the top and checks the condition **again**. While it's `True`, the block runs again. As soon as it's `False`, Python skips to the first line after the loop.

> [!TIP]
> **Think of the condition as a bouncer at a club.** The bouncer checks your ID: that's the condition. If it passes, you're let in to the club: that's the block. If not, you're turned away, and the program carries on below the loop.
>
> With `if`, the bouncer checks you once. With `while`, every time you finish the block, you're back outside at the door, and the bouncer checks you **again**. You keep getting in until your ID stops passing.

Follow it through:

| `count` | `count > 0`? | What happens |
| --- | --- | --- |
| `5` | `True` | Print `5`, `count` becomes `4` |
| `4` | `True` | Print `4`, `count` becomes `3` |
| … | … | … |
| `1` | `True` | Print `1`, `count` becomes `0` |
| `0` | `False` | Leave the loop, print `Go!` |

**A shorter way to write it.** Changing a variable by a little is so common that Python has a shortcut. `count -= 1` means the same as `count = count - 1`. And `count += 1` means `count = count + 1`. Change your line to `count -= 1` and run it again. Same output.

## Step 4: A loop that never ends

**Break it on purpose.** Delete the `count -= 1` line, save, and run it.

`count` stays `5` forever, so `count > 0` is always `True`, and the loop never stops. Nothing about you changes, so the bouncer lets you back in every time. Your terminal fills with `5`s. This is an **infinite loop**, and every programmer writes one by accident sooner or later.

To stop it, click in the terminal and press **Ctrl + C**. Python stops and shows a `KeyboardInterrupt`. That's not a bug in your code. It just means you stopped it.

> [!TIP]
> **Ctrl + C stops any program that's running in the terminal**, not just Python. If the terminal ever seems stuck, try it. If it copies text instead, you had some text selected. Click once in the terminal to clear the selection, then press it again.

Put `count -= 1` back. When you write a loop, always ask yourself: *what changes inside the loop, so the condition can become `False`?* In other words, what makes the bouncer say no in the end? (This question might be a nice addition to your journal.)

## Step 5: Ask until the answer is right

Loops are perfect for asking again. Add this to the bottom of `loops.py`:

```python
answer = input("What's 7 times 8? ")
while answer != "56":
    print("Not quite. Try again.")
    answer = input("What's 7 times 8? ")
print("Correct!")
```

Run it, and give a few wrong answers before the right one.

Notice the pattern. You ask once **before** the loop, so `answer` has a value to check. Then you ask again at the **end** of the loop, so the answer can change. You'll use this pattern a lot.

Why `"56"` in quotes? Remember from Lesson 0.6: `input` always gives you a string. Take the quotes off, so it says `while answer != 56:`, and run it. Type `56`. It still says *Not quite*! The string `"56"` is not the number `56`, so the condition never becomes `False`. Press **Ctrl + C**, and put the quotes back.

## Step 6: Is it a number?

In Lesson 0.6, typing `forty` as your mark crashed `score.py`, because `int` can't turn `forty` into a number. So check the text first, before you use `int`.

Strings have a built-in check called `isdigit()`. Try it in the REPL. Type `python`, then each of these:

```python
"42".isdigit()
"forty".isdigit()
"42.5".isdigit()
"".isdigit()
```

You get `True`, then `False`, `False`, `False`. `isdigit()` is `True` only when every character is a digit, 0 to 9, and there's at least one. So it's `False` for words, decimal points and empty answers. These are exactly the cases that crashed `int`.

The `.` joins a value to a tool that belongs to it. `isdigit()` belongs to strings, so you write the string, a dot, then `isdigit()`. A tool like this is called a **method**.

> [!NOTE]
> **Python comes with lots of tools built in**, ready to use. You've already used some: `print`, `input`, `int` and `round`. Strings have dozens of methods of their own, like `isdigit()`. Try `"saikou".upper()` in the REPL. You'll see a lot more of these.

One more new word: `not` flips `True` and `False`. Try:

```python
not "forty".isdigit()
```

That's `True`: it's true that `forty` is *not* a number. Type `exit()` to go back to Git Bash.

> [!NOTE]
> **What about half marks, like `42.5`?** `isdigit()` says no, because of the `.`, so for now `score.py` only accepts whole marks. In Lesson 0.12 you'll learn a way to accept half marks too.

Commit `loops.py` with your own message before you go on.

## Step 8: Exercise: the guessing game

First you need a random number. Python comes with lots of extra tools, grouped into **modules**. They aren't loaded until you ask for them. The `random` module picks random things. Load it with `import`, at the top of your file:

```python
import random

```

`random.randint(1, 100)` picks a whole number from 1 to 100. Both ends are included, so `1` and `100` can come up too. Each time you run the program, it picks again.

### Plan it first, in plain English

Before you write any Python, write down the steps in your own words. A plan like this is called **pseudo-code**: it's shaped like code, but written in ordinary language, so you can think about *what* the program does before you worry about *how* to write it in Python. Developers do this all the time, especially when a problem feels too big to start.

Here's the `7 times 8` loop from Step 5, as pseudo-code:

```
ask "What's 7 times 8?"
while the answer isn't 56:
    say "Not quite"
    ask again
say "Correct!"
```

There are no rules for pseudo-code. No quotes needed, no brackets, no errors. It only has to make sense to you. But notice the indenting: it already shows which steps repeat.

Now write the plan for your game, in `guess.py`, **as comments**. Start each line with `#`, so Python ignores it. Think it through: what happens once at the start? What repeats? When does it stop? What happens at the end?

Then turn the plan into Python, one comment at a time, writing the code under each comment. Run it after each piece, so you catch mistakes early. Keep the comments when you're done. They explain your program to anyone who reads it, including you, later.

If you're not sure what your plan or your code should say, these hints help:

- Start with the `import` and the secret number.
- Use the pattern from Step 5: ask once before the loop, then again at the end of the loop.
- Keep asking while the guess **isn't** the secret. Remember to use `int`. The secret is a number, and `input` gives you a string.
- Inside the loop, use `if` and `else` to say *Too high* or *Too low*.
- To count the guesses, start a variable at `1` before the loop, and `+= 1` each time the player guesses again.

> [!TIP]
> **Testing a game with a secret is hard when you don't know the secret.** Use the trick from Lesson 0.7: add `print(secret)` just after you pick it, while you're testing. Then you can check that *too high* and *too low* are right. Delete the line before you commit, or it's not much of a game.

If you get stuck, go back to your plan and check each step, then re-read the hints, and use `print(secret)` to see what's happening. It's also okay to step away for a bit and come back to it. A problem that seemed impossible often looks clearer after a break. If you're still stuck after that, send me the whole error.

## If something goes wrong

- **The terminal fills up, or a program won't stop:** press **Ctrl + C**. Then find what should change inside the loop.
- **The loop never ends, even with the right answer:** you're probably comparing a string with a number. Check for `int`, or for quotes around the number.
- **`NameError: name 'random' is not defined`:** add `import random` at the top of the file.
- **`AttributeError: 'int' object has no attribute 'isdigit'`:** you used `int` before `isdigit()`. `isdigit()` works on the text, so check first, then use `int`.
- **`IndentationError` after moving lines:** select the lines and use **Tab** or **Shift + Tab** until each block lines up with the others.
- **Some other error?** Read the last line and the line number, check that line, and send me the whole error if you're still stuck.
