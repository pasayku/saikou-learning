### 3. `guess.py`

You have two loops inside each other, and neither can end:

```python
while answer > (secret + 20):
    print("Your guess is off by aeons. Try lower.")
```

Nothing in this loop changes `answer`, so the condition stays `True` forever. That's your infinite loop, and **Ctrl + C** stops it. A `while` repeats *as long as* its condition is true. An `if` asks the question *once*. A taunt only needs an `if`.

There's a bigger problem underneath, so the taunts weren't the first thing to go wrong. You have one `if` for too high and a separate `while` for too low. If the secret is `50` and you guess `70`, then `80`, it says "Too high." once, and then the program just ends. Both answers belong in **one** loop, the way the `7 times 8` loop in Lesson 0.8, Step 5 works:

```
ask for a guess
while the guess isn't the secret:
    if the guess is too high:
        say so (cheekier if it's far off)
    else:
        say so (cheekier if it's far off)
    ask again
say how many guesses it took
```

Rebuild it from this plan, keeping your own pieces. Your `isdigit` check needs to run *every* time you ask, not only for the first guess. Today `fifty` as a second guess crashes it. Delete `print(secret)` when you're done. `random.randint` already gives you a number, so `secret = int(secret)` isn't needed either.
