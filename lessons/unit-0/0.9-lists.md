## Step 3: Your first list

Start the REPL by typing `python`. Then make a list:

```python
subjects = ["Maths", "English", "Biology"]
subjects
```

A list starts with `[` and ends with `]`, with a comma between each item. Python shows it back to you:

```
['Maths', 'English', 'Biology']
```

(The REPL shows strings with single quotes. Both kinds of quote mean the same thing.)

How many items are in it? `len` counts them:

```python
len(subjects)
```

That gives `3`.

**Get one item.** Each item has a number, called its **index**, which says where it is in the list. Try these:

```python
subjects[0]
subjects[2]
```

You get `'Maths'`, then `'Biology'`. The first item is at index `0`, not `1`. Python counts how far an item is from the start, and the first item is 0 steps from the start. Almost every programming language counts this way. It feels odd for a week, then it doesn't.

So what's at index `3`? Try it:

```python
subjects[3]
```

```
IndexError: list index out of range
```

A list of 3 items has the indexes `0`, `1` and `2`. There's nothing at `3`.

To get the **last** item, use `-1`. It counts from the end:

```python
subjects[-1]
```

That's `'Biology'` again. It works however long the list is.

**Add an item.** `append` adds one to the end:

```python
subjects.append("Physics")
subjects
```

```
['Maths', 'English', 'Biology', 'Physics']
```

Like `isdigit()` in Lesson 0.8, `append` is a method, so it goes after a dot. It changes the list itself. Check `len(subjects)` again: it's `4` now.

Type `exit()` to go back to Git Bash.

## Step 4: Go through a list with `for`

Make a new file:

```
cd work/unit-0
touch lists.py
code lists.py
```

Type this in:

```python
# Practice with lists and for loops
subjects = ["Maths", "English", "Biology", "Physics"]
for subject in subjects:
    print(f"I study {subject}.")
print("That's all my subjects.")
```

Run it:

```
python lists.py
```

```
I study Maths.
I study English.
I study Biology.
I study Physics.
That's all my subjects.
```

Read the `for` line aloud: *for each subject in subjects*. Python takes the first item and puts it in `subject`, then runs the indented block. Then it takes the next item, and runs the block again. When there are no items left, it carries on after the loop.

| Time round | `subject` is | Prints |
| --- | --- | --- |
| 1st | `"Maths"` | `I study Maths.` |
| 2nd | `"English"` | `I study English.` |
| 3rd | `"Biology"` | `I study Biology.` |
| 4th | `"Physics"` | `I study Physics.` |
| | No items left | `That's all my subjects.` |

You choose the name `subject`. Any name works, but the usual habit is to call the list something plural, `subjects`, and each item the singular, `subject`. Then the line reads like English.

**Why not `while`?** You could do the same with a `while` loop and a counter:

```python
index = 0
while index < len(subjects):
    print(f"I study {subjects[index]}.")
    index += 1
```

It works, but you have to look after `index` yourself, and if you forget `index += 1`, that's the infinite loop from Lesson 0.8. A `for` loop does the counting for you, and it always stops at the end of the list. So:

- Use `for` when you're going through a list, from start to end.
- Use `while` when you don't know how many times you'll go round, like asking until someone types a number, or guessing until they win.

## Step 5: Add up a list

Add this to the bottom of `lists.py`:

```python
marks = [72, 45, 88, 50]
total = 0
for mark in marks:
    total += mark
print(f"Total: {total}")
```

Run it. You get `Total: 255`.

`total` starts at `0`, before the loop. Each time round, the next mark is added to it: 72, then 117, then 167, then 255. A variable that collects a result as the loop goes round is a common pattern. You used one in Lesson 0.8 to count guesses.

The average is the total divided by how many marks there are. Add:

```python
print(f"Average: {total / len(marks)}")
```

That's `63.75`.

Adding up a list is so common that Python has it built in. Open the terminal and start the REPL with `python`. Try:

```python
marks = [72, 45, 88, 50]
sum(marks)
max(marks)
min(marks)
```

You get `255`, `88` and `45`: the total, the highest and the lowest. `sum` gives the same answer as your loop. It's still worth knowing how to write the loop yourself, because not every job has a built-in, like the next one.

Type `exit()` to leave the REPL, then commit `lists.py` again.

## If something goes wrong

- **`IndexError: list index out of range`:** you asked for an index the list doesn't have. Remember the first one is `0`, so the last one in a list of 5 is `4`, or `-1`.
- **`SyntaxError: expected ':'`:** the `for` line needs a `:` at the end, like `if` and `while`.
- **`NameError` with `Did you mean`:** you probably typed the loop variable differently inside the loop. Python suggests the name it thinks you meant.
- **`TypeError: unsupported operand type(s) for +=: 'int' and 'str'`:** one of your marks is in quotes, so it's a string. Marks in a list need no quotes.
- **Your list has fewer items than you typed, and there's no error:** look for a missing comma. `["Silo" "Severance"]`, with no comma, is one item, `'SiloSeverance'`.
- **Some other error?** Read the last line and the line number, check that line, and send me the whole error if you're still stuck.
