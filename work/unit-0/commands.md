# Command Line Notes


| Command | What it means                                                                    |
| ------- | -------------------------------------------------------------------------------- |
| `pwd`   | Shows which folder I'm in, as a path                                             |
| `ls`    | Lists the folders in your current directory/folder, the folder you're working in |
| `ls -a` | Lists files and folders along and also hidden files                              |
| `cd`    | Changes the folder/directory                                                     |
| `cd..`  | Takes you up a folders                                                         |
| `cd ~`  | Takes you your home folder                                                       |
| `mkdir` | Create new folder                                                               |
| `touch` | Create new file                                                                 |
| `cp`    | Create copy of a file                                                           |
| `rm`    | Delete file                                                                      |
| `mv`    | Move/Rename file or folder                                                      |
| `rmdir` | Delete folder                                                                    |
| `clear` | Clears the Teminal                                                               |
|         |                                                                                  |
