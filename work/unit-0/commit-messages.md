# Commit Message Practice

## 1. `stuff`

- **Rules it breaks:**
  - Rule 1, didn't start with a verb.
  - Rule 2, didn't say what it changed.
- **Better:** `Updated the command notes`

## 2. `fixed it`

- **Rules it breaks:**
  - Rule 1, verb is in past tense.
- **Better:** `fix README spelling mistakes`

## 3. `asdfh`

* **Rules it breaks:**
  * Rule 1, doesn't start with a verb
  * Rule 2, doesn't say what it changed
* **Better:** `Delete empty test.txt file`

## 4. `changes`

- **Rules it breaks:**
  * Rule 2, doesn't say what it changed

* **Better:** `Move command.md to work/unit-0`

## 5. `Added the journal entry and fixed the README and renamed practice.txt.`

- **Rules it breaks:**
  * Rule 1, verbs are in past tense
  * Rule 3, too wordy
  * Rule 4, combines more than 1 commit
- **Better:**
  * `Add journal entry  `
  * `fix README`
  * `rename practice.md`

## 6. `wip`

- **Rules it breaks:**
  * Rule 1, doesn't start with a verb
  * Rule 2, doesn't say what it changed
- **Better:**
  * `Add first table to notes.md`
